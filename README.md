# ForensicLex

Sitio web creado con HTML, CSS, JavaScript y Vercel.

## Estructura

- `index.html` — Página principal
- `style.css` — Estilos
- `script.js` — Lógica de la aplicación
- `vercel.json` — Configuración de Vercel (redirecciones, headers)
- `api/contacto.js` — API para procesar formularios
- `api/saludo.js` — API de ejemplo

## Despliegue

1. Sube los cambios a GitHub: `git push`
2. Vercel despliega automáticamente
3. Visita: https://forensiclex.com
